Format E37 admin stöder JPG och PNG, men inte WebP. Bilder serveras automatiskt som WebP av Cloudflare där det är fördelaktigt. PNG ger perfekt kvalitet och stödjer transparent bakgrund, men ger betydligt större filer — passar bäst för mindre sortiment med höga kvalitetskrav.

⚠ E37 admin stöder inte WebP — använd JPG för uppladdning.

⚠ Dina bilder är JPG/WebP — PNG-export ger ofta mycket större filer utan kvalitetsförbättring.

Bakgrund
Kvalitet 85%
Padding 0% Lägger till luft runt produktbilden. 5% på en 1500 px canvas ger 75 px marginal på varje sida. Bilden skalas ner för att ge plats åt paddingen — canvasstorleken förblir oförändrad.
Skärpa 0 Nedskalning kan göra bilden lite mjuk. Skärpefiltret förstärker kanterna efteråt med en konvolutionskärna. 0 = av. Höga värden (70+) kan ge synliga kantartefakter, särskilt på platta bakgrunder.
Om bilden redan är mindre än målstorleken placeras den centrerad på en vit yta utan att förstoras. Förstoring försämrar bildkvaliteten.
Detekterar automatiskt bakgrundsfärgen (baserat på bildernas hörn) och klipper bort enhetlig marginal runt produkten innan optimering. Fungerar bäst på bilder med ren vit eller enfärgad bakgrund.
Söker automatiskt rätt kvalitetsnivå för att varje bild ska hamna under målstorleken. Min 50% kvalitet — bilden kan bli lite större om den inte kan komprimeras tillräckligt. Påverkar inte PNG.
